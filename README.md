# Mutual Fund Analytics

## Project Overview
This project analyzes mutual fund performance and risk using Python, PostgreSQL, and Tableau. The objective is to transform raw financial data into meaningful investment insights.

## Technologies Used
- Python
- PostgreSQL
- Tableau
- Pandas
- NumPy
- Matplotlib

## Workflow
1. Data Collection
2. Data Storage in PostgreSQL
3. Data Cleaning & EDA
4. Performance Analytics
5. Risk Analysis (VaR & CVaR)
6. Tableau Dashboard Development

## Key Metrics
- Alpha
- Beta
- Sharpe Ratio
- Rolling Sharpe Ratio
- Value at Risk (VaR)
- Conditional Value at Risk (CVaR)

## Dashboard Features
- Fund Performance Tracking
- Benchmark Comparison
- Risk Visualization
- Category-wise Analysis

## Project Outcome
Developed an end-to-end Mutual Fund Analytics platform that helps evaluate fund performance and investment risk using data-driven insights.
